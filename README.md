#  Air Quality Prediction - India

**Live Demo:** https://ab9560.github.io/Air-Quality---prediction-india/

ML model to predict PM2.5 / AQI for any city in India. MAE: 16.34

###  Features
- Predict AQI for any city
- Input: PM2.5, PM10, NO2, SO2, CO, O3
- Clean responsive UI

### Tech Stack
- Python, Pandas, Scikit-Learn, RandomForest
- HTML, CSS and javascript.
- GitHub Pages

###  Files
- index.html - Website
- predict.py - ML logic
- clean.py - Data cleaning
- raw.csv / full_clean.csv - Data
